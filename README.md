## 本地预览

安装Python后，在本仓库根目录运行：

```sh
python -m http.server 8000 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8000/`。没有npm、React、后端或数据库依赖。直接打开index.html也可浏览，但建议使用静态服务器。
